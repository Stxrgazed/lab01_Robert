In this project we were asked to create 2 files with 2 different functionalities using GitHub.

RUN APP INSTRUCTIONS:

-IODisplay.py- 
First you will be asked for a sequence of numbers. Enter the sequence.
Then you will be asked for the length of an array that you will create. Enter the desired length.
Then depending of the length, you will be asked to enter the elements inside the array one by one. 
Finally after filling the array, both the sequence and the array will be displayed.

-ReadFile.py
First you will be asked for the name of the file you would like to open. Enter the filename inside the same folder as the script or the full file path. 
Then the program will check whether the file exists or not.
If the file exists it will display its contents, otherwise it will output a "File not found" error.
